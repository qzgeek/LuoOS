# 官方 QQ 回归与本地 Folia 验证

## 自动回归

前置：JDK25、Python3、Gradle 已缓存依赖。先构建实际插件：

```sh
./gradlew :folia:26.1.2:shadowJar --no-daemon
python3 tests/run-official-regressions.py
```

脚本在临时目录编译测试并使用构建出的插件 Jar，不复制实现、也不拿 SQL 脚本冒充 Java 验证。

| 测试 | 项数 | 覆盖内容 |
|------|------|---------|
| `OfficialBindingRegression` | 16 | 真实 Java + SQLite 身份安全：待验证分表、错误/过期/重放、并发抢占、数据库故障回滚、旧版归档、重启、失败原因区分 |
| `OfficialMediaRegression` | 10 | 本地 HTTP 契约：prepare→PUT→finish→files 全链路、字节与校验和、预签名 PUT 不带机器人 Authorization、分片序号 0 或 1 两种真实格式、错误停止、非法输入拒绝 |
| `CommandParityRegression` | 17 | 真实处理器/仓储/HTTP 适配：公开菜单、未验证权限拒绝、封禁解封、SQL 故障不报成功、数字游戏ID删除、重置密码分通道（官Q邮件／传统私聊）、表情保留、乱序回复隔离、重复投递、群哈希碰撞、@目标拒绝与缺目标提示 |
| `OfficialAdaptRegression` | 5 | 群成员进退群→白名单冻结/恢复、未验证成员跳过、resume 条件判断、可重试错误码区分 |
| `HelpTextCheck` | 3 | 调用真实 `handleHelp` 抓取文本：官Q不得出现 `@QQ` 与「私聊发送」、必须含邮箱与绑定步骤；两条通道说明列按显示宽度对齐 |

所有 QQ、OpenID、Token 均为测试夹具。HTTP 只监听 127.0.0.1；SMTP 是明确的测试替身。不联网到腾讯、不登录真实 QQ、不修改生产数据库。

原有入口保留：`sh tests/run-official-binding-regression.sh`（等价于运行全部回归）。

## 实际 Folia 烟雾测试

以下测试源码仅供隔离测试服使用，**绝不能装进生产服**：

- `OfficialQQFoliaSmoke.java`：在本地 Folia 中调用真实的 OfficialQQBot → BotCommandHandler → BotStatusService，使用本地 HTTP 平台替身接收文件与消息。验证帮助菜单、实际生成 1500×700 PNG 状态卡并发送类型7、自定义触发词与在线人机列表。
- `ConfigResolutionSelfCheck.java`：遍历全部配置别名，确认每个键都能在新分组结构下真实解析。**这是针对「配置静默失效」的自检** —— 曾出现 18 个键读了旧扁平名却在新配置中不存在，不报错但用硬编码默认值。自检在空配置与生产配置下均应报「未解析键 0」。

两者在测试服只监听环回地址、不复制生产数据，完成后主动关闭测试服。日志中的 PASS 区分「真实 Folia + 真实渲染」与「本地 HTTP 替身」，不是腾讯线上验收。

## 关于官方 intent 的验证方法

排查「成员事件是否真的下发」时，可直接连网关逐一测试 intents 授权情况
（参考本轮所用的一次性探针思路，**每次必须使用全新连接**）：

```
仅群/C2C消息  1<<25        → 期望 READY
仅群成员事件 1<<24        → 期望 READY
组合         50331648     → 生产实际使用的值
```

注意：**复用同一个 WebSocket 连接连续测试多个 intents 会读到脏帧，得出「被拒绝」的错误结论**。本轮曾因此误判 intent 未授权，改用独立连接后确认全部已授权。

## 上线前仍需人工验证

1. 使用新生成的 AppSecret/邮箱授权码，勿提交仓库或输出到日志。
2. 在受控测试群验证帮助、PNG 状态卡显示、自定义触发词、在线人机。
3. 用独立测试账号验证白名单、管理员操作，以及 **@未验证成员 / @已验证成员 / 直接填 QQ 号** 三种写法的提示。
4. 验证 `重置密码`：官Q走邮件、传统走私聊，两者失败均应回滚密码。
5. 验证成员退群冻结与重新进群恢复（两条通道各一次）。
6. 检查平台授予的 intent 权限（群消息 `1<<25`、群成员 `1<<24`）与图片分片上传权限。
7. 长期稳定性（长时间断线重连、令牌跨过期点）仍需在真实环境观察，本地测试无法替代。

本轮只构建并运行 Folia 26.1.2。MySQL、其他 Minecraft 目标未包含在自动回归结果里。
